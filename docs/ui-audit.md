# UI 审核与架构调整

日期：2026-11-13。范围：首页、节点卡片与列表、概览、费用面板、详情页、图表筛选、顶栏及底部浮层。使用 monitor.ikuyu.com 的真实 9 个节点验收；没有修改主题设置 schema、存储键和延迟计算口径。

## 已修复的问题

| 问题与触发条件                                  | 原因                                                                       | 处理                                                                                       |
| ----------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |

## 架构结果

- 首页组合、筛选策略、滚动记忆、工具栏、结果区和弹窗各有明确入口。
- 节点卡片的资源、网络和延迟区域独立维护，延迟依旧使用同一共享统计。
- 概览统计、基础概览卡、费用弹层与地理可视化解耦。
- 负载图拆成请求 hook、纯 option 工厂和展示组件；延迟图请求生命周期独立。
- 搜索和排序是框架无关函数，便于独立验证。完整调整地图见 [architecture.md](./architecture.md)。

## 移动端反馈后的修正

- 地球恢复按可用宽度展示，手机端的汇总卡贴合地球下缘；在线数量移到左上角。
- 去掉分组选中态的绿色描边和费用标题中挤占空间的币种字样。
- 矩形 UI 表面统一采用原生 `corner-shape: squircle` 连续曲率圆角，圆形状态灯和头像保持圆形；旧浏览器保留普通圆角兼容。

## 分组选中态和动画性能反馈

- 分组选中态改为中性灰底和正文色；鼠标实际点击后检查填充、边框和焦点阴影，绿色边框透明、绿色 ring 宽度为 0，键盘焦点使用灰色 outline。
- 发现 cobe 2.0.1 在收到 width / height 时无条件写入 canvas 绘图缓冲区。原渲染循环每帧都传尺寸；改为仅在尺寸变化时传入。
- 同一台机器、前台 Chrome、相近 2.2 秒采样：改前 264 个帧间隔、约 8.34ms 均值、width / height 各写入 265 次；改后 264 个帧间隔、约 8.33ms 均值、两者均为 0 次。两次都未出现超过 25ms 的帧间隔，不能据此宣称所有设备帧率都提升。
- 地球拖动使用时间步进、指数跟随和松手惯性。自转角速度统一为 rad/ms，60Hz / 120Hz 不再改变速度；暂停、后台恢复和减少动态效果均有明确处理。
- 移动标签去掉 blur 和 backdrop-filter，保留 transform / opacity；概览入场移除模糊，节点错峰延迟从最多 420ms 缩短到 144ms。
- 独立断言覆盖 60 / 120Hz 速度一致、惯性一致、停止收敛、减少动态效果、后台长间隔与俯仰边界。没有新增测试框架。

- 原生鼠标拖动后，在暂停自转状态下采样：前 400ms 的 48 帧位置持续变化，2 秒后位置收敛为同一值，验证了松手惯性与最终停止。

## 分组焦点轮廓裁切修正

- 多分组实际点击复现：浏览器在鼠标点击后仍匹配 `:focus-visible`，原来的外扩焦点轮廓在横向滚动容器左边界被裁断，尤其「全部节点」明显；此前修改选中背景并未处理这一状态。
- TabsTrigger 记录本次焦点的指针来源，指针点击时不绘制轮廓，按键或失焦后清除该状态；键盘焦点向内绘制 2px，避免滚动容器裁切。
- 原生鼠标多次切换全部 / 线路机 / 落地机后，选中项 `outline-style: none`；按 ArrowRight 切换后保留 `2px solid`、`outline-offset: -2px` 的键盘焦点。

## 动画衔接、退化连线与悬浮条

- 地球的美国异常直线来自 US → US 的首尾重合弧线：cobe 将控制点向外抬高，重合端点会生成原路折返的径向曲线。生成连线时按球面距离过滤重合坐标，不再将其送入渲染器。
- 真实页面：全部节点时 WebGL 弧线实例数为 1；只有美国节点的线路机分组中，400ms 内球体绘制 49 次、弧线绘制 0 次，拖动后无径向突线。
- 底部访客条改为实色卡片背景、细边框与轻阴影，展开与收起的 backdrop-filter 都为 none。
- 移除分组作为结果区 / 节点 key 的做法。真实切换全部 → 线路机时，两张 DMIT 卡片保持原 DOM；返回全部后保留，只有重新出现的节点播放 4px、200ms 入场，动画结束释放 transform。
- 再次抓取地球时从当前可见角度接手，清除旧目标与惯性；手动拖动后用 240ms 时间常数渐进恢复自转，地区标签按球面深度渐隐，触屏 touch-action 为 pan-y。
- 运动断言覆盖：60 / 120Hz 自转恢复积分一致、恢复速度渐进、二次抓取不中断位置、不同尺寸拖动一致、60 / 120Hz 输入事件得到相同惯性、静止收敛与减少动态效果。
- 连线断言覆盖：同地区、不同地区、经度 ±180°、极点与无访客坐标。

## 访客详情与图表展开

- 访客详情独立使用 0fr → 1fr 行高过渡，摘要保持单行且决定面板宽度；折叠详情设置 aria-hidden / inert，Escape 可收起。
- 真实页面采样：宽度全程 387.82px，高度由 30px 经 175.66 / 205.99px 连续展开至 213px；收起经 85.28 / 40.72px 回到 30px。连续反向切换后高度、状态和内容均正确，无横向溢出，backdrop-filter 为 none。
- 图表弹窗使用视口约束高度与内部滚动，懒加载保留占位；保留节点至关闭动画结束后再清理，避免条件卸载跳过退场。
- 真实页面打开后弹窗高度 729px，图表已绘制；300ms 内背景地球绘制 0 次。Escape 关闭后先进入 closed，约 190ms 后卸载，随后 250ms 内地球恢复绘制 31 次。
- 390 × 844 截图确认标题和关闭按钮固定在顶部，线路统计与图表在内部滚动，弹窗没有横向越界。减少动态效果路径按代码检查，未做 Safari 实机验收。
